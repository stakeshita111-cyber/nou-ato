3. tasks & student_tasks (カリキュラム教材 & 個別割当タスク)

講師が作成するマスター教材テンプレート (tasks) を基に、受講生ごとにインスタンス化されて個別進捗・現場写真・チェックリストを保持する (student_tasks) 設計です。

4. journals (交換日記・AIしるべぇチャット対話ログ & 農園ナレッジ)

受講生の日々の作業日誌・質問メモおよびAI相談ログを統合管理。is_approved = true のレコードは農園固有の推奨ナレッジとしてAIしるべぇ (RAG) の類似検索対象に自動昇格します。

🛡️ Row Level Security (RLS) ポリシー設計規準

マルチテナント保護と受講生・講師のアクセス厳格分離

👨‍🎓 受講生 (student) 認可ルール

  • 自身の student_id = auth.uid() に一致するレコードのみ SELECT / UPDATE
  • 論理削除済み (deleted_at IS NOT NULL) の場合は全操作拒絶
  • 他生徒の非公開日誌や個人情報へのアクセスを完全遮断

👨‍🌾 講師 (teacher) 認可ルール

  • 所属農園 (farm_id) に紐づく全受講生・全畝・全日誌の閲覧・編集権限
  • 受講生の日誌に対する承認 (is_approved = true) および返信権限
  • タスクテンプレートの作成・割当・編集権限
