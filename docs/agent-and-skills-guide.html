⚡ 自動化スキル一覧 (.agents/skills/*)

定型化された自動作業・生成・最適化手順を呼び出すスキルプロトコル

code-optimizer NEW ★ コード軽量化

品質と型安全性を維持したまま、重複ロジックのカスタムフック化、デッドコード除去、Server Component化を全自動で実行し、軽量なコードベースに整理します。

呼び出しコマンド例:
「code-optimizer スキルを適用して、hooks/ 周辺の重複コードを整理して」
doc-visualizer NEW ★ HTML視覚化

リポジトリ構造、Next.jsルーティング、コンポーネント依存関係、Supabaseデータフローをスキャンし、ブラウザで開ける美しいHTMLマップ（docs/）を即座に生成します。

呼び出しコマンド例:
「doc-visualizer スキルを実行して最新構造をHTMLマップで出力して」
analyze-build-errors ビルド・型エラー解析

npx tsc --noEmit や npm run build のエラーメッセージを自動解析し、原因箇所を特定してコードの修正Diff案を出力します。

呼び出しコマンド例:
「analyze-build-errors スキルで、現在の型エラーの原因と修正案を出して」
sync-supabase-types Supabase型定義同期

SupabaseのDBスキーマ変更があった際に、TypeScript型定義（types/supabase.ts）を最新状態で同期します。

呼び出しコマンド例:
「sync-supabase-types スキルで型定義を再生成して」
