Supabase DB 直結 ＋ HTML5 BroadcastChannel API によるリアルタイム双方向連動アーキテクチャ

講師操作 ➔ 生徒 生徒入力 ➔ 講師 Supabase / BroadcastChannel

🔀 講師 ↔ 生徒 リアルタイムデータ双方向つながり図

最新実装されたすべての相互データフローと動作メカニズム

機能 1

🌾 キャンバス区画自由配置 ＆ 畝(ベッド)の増減双方向同期

リアルタイム同期
1. 講師画面 (TeacherFarmCanvas)

キャンバス上でカードを自由ドラッグ (AABB衝突自動磁石スナップ)

「＋ 畝(ベッド)を1つ追加」または「🗑️ ゴミ箱削除」を実行

➔ (Supabase DB & Broadcast) ➔
2. データ層 (Supabase & BroadcastChannel)

`farm_beds` / `farm_plots` へ直接 INSERT / DELETE 保存

BroadcastChannel 経由で全画面へ0.01秒通知

3. 生徒画面 (StudentFarmRecord)

自分の担当区画の畝(ベッド)リストに即座に反映

増えた畝 (例: 畝 1-8) や削除がリアルタイム連動

機能 2

📝 生徒の畝指定タスク完了・観察記録 ➔ 講師画面リアルタイム発光・確認

フィードバック循環
1. 生徒画面 (TaskDetail / RecordView)

タスク完了時に対象畝 (例: 畝 1-1) を選択して報告

草丈、作業内容、写真、観察ノートを入力して送信

➔ (Supabase INSERT) ➔
2. データベース (crop_records)

Supabase `crop_records` テーブルへ永続化保存

`farm_beds` の状態を更新

3. 講師画面 (TeacherFarmCanvas)

該当の畝が「✨ 更新あり (エメラルドグリーン)」に即時点灯！

タップして生徒の全作業メモ・収穫・写真を詳細閲覧

機能 3

📅 生徒の畝別時系列タイムライン ＆ 過去ログの「✏️ 編集」・「🗑️ 削除」

管理機能
① 時系列タイムライン (Timeline)

選択した畝ごとに過去の全タスク報告・写真・成長記録を新しい順でグラフ表示。

② 過去記録の修正 (✏️ 編集)

過去の誤記や更新があった場合、モーダルから上書き保存 (Supabase UPDATE)。

③ 誤ログの消去 (🗑️ 削除)

不要なテストデータや誤投稿を Supabase から完全消去 (Supabase DELETE)。
