# コード最適化・軽量化スキル (Code Optimizer Skill)

以下の手順に従って、コードベースの軽量化と品質向上を自律的に実施してください。

## 実行手順

1. **デッドコード・未使用モジュールの検出と整理:**
   - プロジェクト全体をスキャンし、参照されていない古いコンポーネント、一時的なテストコード、未使用のインポート文を検出して整理する。
   - インポートパスや未使用変数のクリーンアップを行う。

2. **重複ロジックの共通化 (DRY原則):**
   - 複数のコンポーネントで重複しているSupabaseのデータ取得処理、トースト通知、ダイアログ表示状態などをカスタムフック（例: `hooks/` 配下）や共有ユーティリティ（例: `lib/` 配下）へリファクタリングする。

3. **Server Components / Client Components の境界最適化:**
   - 不必要な `"use client"` ディレクティブを取り除き、可能な限り Server Components に寄せることでクライアントJSのバンドルサイズを削減する。

4. **型安全性および動作検証:**
   - 最適化・軽量化の実施後は、必ず `npx tsc --noEmit` および `npm run build` を実行する。
   - 既存の機能や動作が壊れていない（デグレゼロ）ことを実証してから結果を報告する。
